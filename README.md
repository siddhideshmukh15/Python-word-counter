# Word Counter

A simple Python project that counts the number of words, characters, spaces, characters without spaces, and sentences in the entered text.

## Features

* Counts total words
* Counts total characters
* Counts characters without spaces
* Counts total spaces
* Counts total sentences

## Concepts Used

* `input()`
* `print()`
* String methods
* `split()`
* `replace()`
* `count()`
* `len()`
